# Problem A — Counting Inversions

## Compile

```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic main.cpp -o main
```

## Run

```bash
./main < input.txt 
```

## Test cases

**Input**
```
5
2 4 1 3 5
```
**Output**
```
3
```

**Input**
```
6
5 4 3 2 1 0
```
**Output**
```
15
```

**Input**
```

1 2 3 4
```
**Output**
